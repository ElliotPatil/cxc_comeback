Files:
- index.html: the standalone study dashboard.

How to use:
1. Extract this ZIP.
2. Open index.html in Chrome or another modern browser.
3. Your changes are saved locally in that browser on that device.
4. Use Export backup regularly to save a JSON backup; use Import backup to restore it.

Important:
- This prototype uses browser localStorage. It does not have Firebase or cloud sync connected.
- Clearing browser site data may erase locally saved progress, so export backups.
- Internet may be needed for the optional web fonts; system fallback fonts are included.
